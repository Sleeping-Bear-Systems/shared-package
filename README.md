# @sleepingbear/shared

This repository builds the `@sleepingbear/shared` package that contains shared code for Datastar web applications.

## Scripts

### Linting & Formatting

- `npm run biome:check` checks the repository with Biome.
- `npm run biome:ci` runs Biome's CI checks.
- `npm run biome:fix` applies Biome's automatic fixes.

### Build

- `npm run build` builds the TypeScript project.
- `npm run build:force` forces a TypeScript project build.

### Publish

- `npm run prepare` builds the package; npm runs this script during package preparation.

### Test

- `npm test` is a placeholder that exits with an error because no tests are configured yet.
